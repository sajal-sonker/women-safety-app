# Android application

React Native0.88.1/TypeScript with Kotlin Firebase auth, encrypted SOS journaling and bounded location foreground service. This workspace shares dependencies and generated contracts with the repository root.

Use the root [RUNNING.md](../../RUNNING.md) for installation, emulated accounts, Metro, debug builds and USB/emulator setup. [Native interface](docs/native-interface.md) documents the JS/Kotlin ownership boundary; [platform evidence](docs/platform-spikes.md) separates actual compilation from pending real-device tests. iOS, monitoring/ML, fake PIN/call and experimental hardware triggers are outside Phase1/2.
